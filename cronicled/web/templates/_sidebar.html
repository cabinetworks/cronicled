{# cronicled/web/templates/_sidebar.html #} {# The persistent navigation: one entry per inbox, every time, on every page this server serves -- so getting from a per-inbox page back to the summary, or across to a different inbox, never depends on the browser's Back button. `sidebar` is built once, in `web.app._sidebar_context`, and handed to every `render()` call alongside whatever else that page needs; this partial does no counting or filtering of its own. It is `None` -- not an empty list -- when no store is wired, and this include renders nothing at all in that case: a link into `/{inbox}` that a store-less install could not answer would be worse than no navigation there (see `_sidebar_context`'s own docstring).
